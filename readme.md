# Arc Tab Switcher

Restyle le panneau Ctrl+Tab de Zen façon Arc : panneau flou centré, cartes arrondies avec aperçu, carte active entourée d'un anneau clair.

Nécessite l'option "Ctrl+Tab cycles through tabs..." (Réglages > Général > Onglets). Désactiver les autres mods qui restylent le panneau Ctrl+Tab.
